# Итерация 0.2 — место смотрителя

Уточнение пользователя: ориентир финальной графики — No, I'm not a Human / Arctic Eggs; вид от первого лица за защищённой стойкой, приходящие посетители, выдача через шлюз, фактурные предметы/бумаги, аутентичное главное меню. Разговор не должен закрывать NPC. Сначала закрепляем этот способ игры на Нине, затем масштабируем сюжет, окончательную графику дорабатываем позже.

## Совместная работа

Оркестратор: scripts/ui/game_ui.gd, scripts/main.gd, project.godot, общий контракт, документация, интеграция и сохранение. Ядро GameStore/StateReducer и команды остаются прежними.

Агент помещения: scripts/presentation/* и scenes/room/*, scenes/objects/*, assets/materials/*, assets/shaders/*. Пересобирает комнату и камеру.

Агент образа: только assets/characters/* и docs/nina-art.md. Создаёт собственный PNG со сглаженной альфой через built-in imagegen, без редактирования чужих файлов.

Агент проверок: только tests/* и docs/acceptance-02.md. Проверяет сохранение правил, новые координаты, одну точку зрения, компактные панели, приход/выдачу/уход.

## Положение игрока и помещения

Godot forward -Z. Все ракурсы — поворот из одной точки `EYE = Vector3(0,1.62,1.25)`; камера не летает по комнате. window смотрит на посетителя у (0,1.52,-1.25), FOV48 после проверки композиции; desk — на стол перед собой; shelf — на стеллаж слева; personal — вниз под стол справа. Можно удерживать ПКМ для ограниченного поворота головы. Кнопки 1–4 остаются доступными.

Стойка/решётка около z=-0.75; лицо Нины видно в центральном проёме. Полка на стороне сотрудника, а не за посетителем. Позиции P01 (публичная константа room.PACKAGE_POSITIONS): shelf=(-1.65,1.16,0.65), desk=(-0.28,0.94,-0.02), personal=(0.60,0.25,0.65). Защищённый передаточный блок справа: hatch=(0.72,0.94,-0.62).

Нина приходит из дальней части пассажирского зала после START. Предыдущий started=false — её нет у окна. При RESTART из разрешённого обращения возвращается исходное состояние. После решения посетитель некоторое время остаётся для реакции, затем уходит. Все анимации принадлежат представлению; история не зависит от таймера.

## Публичные операции представления

room: `apply_snapshot(snapshot)`, `set_input_enabled(bool)`, `set_hovered(String)`, `rotate_package(float)`, `set_reduced_motion(bool)`, `set_view(String)`. Свойства `input_enabled`, `visitor_phase` (absent/arriving/waiting/leaving/gone), `transfer_active: bool`. Сигналы `target_clicked(String)`, `visitor_arrived`, `handover_finished`.

Техническая выдача по-прежнему фиксируется ISSUE_PACKAGE сразу; из перехода desk→issued представление анимирует существующий P01 в защищённый блок: внутренняя дверца закрывается прежде открытия внешней, затем пакет исчезает. Две дверцы одновременно не открыты. Сигнал handover_finished — после анимации; время не больше 2 с при обычном движении. Повторный apply_snapshot не повторяет выдачу. Первый кадр загруженного issued-пакета просто скрывает его. Любая анимация отменяется новым RESTART.

camera: прежние get_camera/focus/reduced_motion/view_changed, публичная const EYE; focus меняет ориентацию из той же точки. Команда 1 возвращает взгляд к окну, а ПКМ поворачивает голову только если `look_enabled` (main переключает по modal_changed).

P01: прежние методы set_opened/set_highlighted; локальное визуальное вращение не меняет GameStore. На полке и под столом крышка закрыта. На столе она открыта после осмотра, пока выбран вид desk. Возвращаясь к посетителю, сотрудник опускает крышку, чтобы она не заслоняла лицо. `opened` в истории и знания сохраняются. main соединяет camera.view_changed с room.set_view; обновления реплики не открывают крышку повторно. Разговор сам переводит взгляд к окну.

room может загрузить `assets/characters/nina-v1.png`, если он уже существует; иначе оставить временную фигуру. Основная геометрия скрывается, когда PNG используется, целевой collider остаётся. Пропорции изображения и центр лица уточняет агент образа в docs/nina-art.md. Никаких чужих игровых ассетов.

## UI

Сохраняются методы render/open_target/_show_document/_show_comparison/_show_inspection/_inspect_detail/_show_conversation/_show_decision/_decide/_restart/_close_modal, поля snapshot/modal/_modal_kind/_start_screen. Названия кнопок из 0.1 можно сохранить для тестов. `sidebar` — компактная панель действий (не постоянная широкая карточка с полным текстом). Разговор — немодальный небольшой нижний блок, NPC виден, `modal_changed(false)`. Бумаги/решение/осмотр блокируют 3D-клики, но занимают ограниченную часть экрана без полной непрозрачной подложки. Чтение бумаг не меняет положение вещей.

Выдача: UI после решения показывает реакцию внизу, а не полноэкранную концовку. Фокус window позволяет видеть защищённую передачу. Решение остаётся окончательным с момента команды. Сюжет не расширяется за Нину.

Меню: самостоятельный атмосферный экран входа; при нажатии «Начать смену» видимый этап подготовки/загрузки сцены, затем приход Нины. Для уже загруженной маленькой сцены не рисуем фиктивный процент. Звук всё ещё после согласованного старта, отключение сохранено.
