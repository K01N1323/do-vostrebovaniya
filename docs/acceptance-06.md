# Приёмка 0.6 — Фёдор и два последовательных обращения

21 октября 2026, текущий Mac пользователя, Apple M4. Godot 4.7.2 stable `ed1daf0bf`, GDScript, Compatibility / OpenGL 4.1 Metal.

## Реализовано

Нина → завершение её обращения → уход и закрытие передаточного блока → «Следующий посетитель» → Фёдор. Переход во время ухода заблокирован. У Фёдора собственные бумаги и портрет, разговоры о доме, работе и синей краске, три реакции на решение.

P02 — объёмный кирпич в рабочей рубашке. Проверяемые признаки: скошенный угол, синяя полоса под белой штукатуркой, тёмная заплатка на воротнике. Деталь выбирается в 3D внутри окна осмотра или кнопкой, открывает собственный крупный план. «Весь свёрток» возвращает общий вид. Осмотр краски открывает соответствующий вопрос.

Выдать / оставить / присвоить завершают оба обращения. Простое возвращение на полку оставляет обращение активным. История Нины и местонахождение P01 сохраняются при работе с P02; чужие признаки и получатель отклоняются. Пакеты размещаются раздельно, у каждого одна запись состояния. В личном месте добавлена отдельная опора P02; подписи физических бумаг меняются вместе с обращением.

Графические проходы: выдача обоих — 1280×800; хранение обоих — 1000×700; присвоение обоих — 1440×900. Во всех девяти сочетаниях решения проверены ядром; через графический ввод пройдены три перечисленные пары. Проверены недоступность кнопки следующего посетителя во время ухода, все три цели внутри осмотра P02, дополнительная реплика, возврат на полку без завершения и прежний результат Нины.

Первый просмотр кадров выявил вывернутые боковые грани кирпича, несмотря на успешный ввод. Порядок треугольников исправлен, проверка внешних нормалей и лиц добавлена отдельно. После этого исправлены обзор верхней полки, расположение двух личных вещей и их опоры. Итоговые кадры просмотрены; в [screenshots/v0.6](screenshots/v0.6) отобраны 8 кадров и manifest полного прогона.

При headless-запусках внутри ограниченного окружения macOS дополнительно выводила ошибку чтения системных CA-сертификатов `get_system_ca_certificates`. Игровые сценарии завершились успешно. Финальная проверка последовательности, графический рендер и экспорт/проверка PCK выполнены в обычном окружении; их журналы без ошибок проекта.

## Границы этапа

Это два законченных обращения, а не полная игра. После Фёдора интерфейс прямо сообщает о конце доступного фрагмента. Далее по плану — Вера и Леонид Мельниковы/P03. P04–P08, финальные документы, три финала и файловое сохранение пока не реализованы; перезапуск начинает всю смену с Нины.

Ввод воспроизведён программными событиями внутри движка. Полное ручное испытание ОС-мышью, длительный замер FPS и художественное утверждение пользователем этим отчётом не заявляются. Посетители используют рисованные Sprite3D с небольшим движением; полноценная анимационная и звуковая постановка остаётся последующим этапом.
